# Architecture Decision Records

ADRs are stable architectural constraints, not aspirational feature lists.

- [ADR-0001](0001-constitutional-kernel.md): independent constitutional kernel, not a general framework.
- [ADR-0002](0002-hyperedges-as-collectives.md): hyperedges possess separate bounded authority.
- [ADR-0003](0003-fail-closed-audit-before-effect.md): fail closed and audit before the side effect.
- [ADR-0004](0004-prototype-trust-limits.md): no production security claims before authentication and broker isolation.

Revisions require tests and explicit rationale. Never silently change a normative ADR because a demo becomes inconvenient.
